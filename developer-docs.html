01 / FIRST CONNECTION

How to set up a camera

Camex AI is described as working with IP cameras that support RTSP streaming, allowing existing CCTV infrastructure to be used without replacing hardware.

  1. ConnectEnsure the camera is powered and connected to the network.
  2. Assign an addressA static IP address is recommended.
  3. Enable streamingEnable RTSP streaming in camera settings.
  4. Collect credentialsNote the username, password, IP and port.
  5. Connect to CamexAdd the RTSP URL to the Camex dashboard.
02 / STREAM FORMAT

What is an RTSP URL?

RTSP (Real-Time Streaming Protocol) is used to stream live video from IP cameras to external systems like Camex AI.

RTSP URL FORMAT
rtsp://username:password@camera-ip:port/stream-path

Replace placeholders with your camera credentials, IP address, port and stream path. Do not share credential-filled URLs publicly.

03 / CAMERA INTERFACE

Generate an RTSP URL

  1. Log in to the camera web interface.
  2. Navigate to Network or Streaming settings.
  3. Enable RTSP or Live Stream access.
  4. Copy the stream path provided.
  5. Combine it with the IP, port and credentials.

05 / FOCUS THE ANALYTICS

Create zones in a camera

Zones help focus analysis on entry points, queues, restricted areas and exits.

  1. Select a camera.
  2. Open Zone Configuration.
  3. Draw zones on the video frame.
  4. Assign a purpose such as Crowd, Queue, Restricted or Exit.
  5. Save and activate zone analytics.

09 / DEVELOPER FAQ

Frequently asked questions

Expand a question to explore integration notes. Statements below summarize the supplied documentation and should be confirmed against your current deployment.

What camera models and protocols are supported?

The supplied text lists RTSP (H.264/H.265), ONVIF Profile S and HTTP/MJPEG, and names Hikvision, Dahua, Axis, Bosch and Hanwha as examples. Proprietary SDK-only models are described as unsupported. Confirm the current compatibility list.

Can Camex connect to NVRs or DVRs?

The supplied text describes RTSP ingestion or ONVIF discovery for NVR/DVR streams. Direct camera access is recommended there for lower latency and reliability in mission-critical deployments.

How can alerts integrate with third-party systems?

The supplied text lists webhook, REST API and MQTT integrations, with example integrations including ServiceNow, Bosch Building Integration, LenelS2 OnGuard, Splunk and QRadar. Availability should be confirmed.

Are real-time and historical APIs available?

The supplied text describes WebSockets or Server-Sent Events for live delivery, HTTP endpoints for historical retrieval, and JSON, CSV or NDJSON export. It lists OAuth2 or API keys for authentication.

Can we use a custom AI model?

The supplied text lists TensorFlow SavedModel/TFLite, PyTorch TorchScript, ONNX and compiled C++ libraries. Models are expected to accept RGB frames and return standard detection fields.

How are zones configured programmatically?

The supplied text describes REST API management or SVG floorplans with labelled zone layers, including polygons, rectangles and tripwires, with time-based or conditional zones where supported.

What metadata can an event include?

The supplied text lists timestamp, camera ID/location, tracking ID, normalized bounding box, confidence, attributes, zone, dwell time, inference latency, device and signed snapshot/clip links. Exact fields depend on configuration.

What hardware is needed?

Capacity depends on stream resolution, frame rate, model and analytics. The supplied text provides indicative examples for Jetson AGX Orin, Intel NUC and GPU servers; benchmark your actual workload before sizing hardware.

How does the system handle crowded scenes?

The supplied text describes reducing frame rate, focusing on active regions or using group-level analytics such as density heatmaps. Validate performance against your scene and camera placement.

Can Camex run edge and cloud together?

The supplied text describes local edge analytics and metadata sync to a central dashboard, including offline operation with later sync. Confirm hosting region, network paths and data policy.

How does Camex address UAE privacy requirements?

The supplied text references on-premise deployment, ADHICS, DHA and UAE PDPL. This page does not certify compliance; request current documentation and validate applicable obligations with your compliance team.

What anonymization is applied by default?

The supplied text says faces and license plates are blurred in event snapshots/clips by default and raw-video retention is configurable. Confirm these settings in the environment you use.

Can models be improved with our data?

The supplied text describes on-site tools to collect, label and fine-tune anonymized footage. Confirm supported workflows and data-handling requirements.

Can we create custom alert rules?

The supplied text describes visual rule builders or YAML/JSON scripts for multi-condition rules, time windows, repetition thresholds and external lookups.

How are updates managed?

The supplied text describes over-the-air updates, manual approval, scheduled maintenance, phased rollouts and offline packages for air-gapped sites. Confirm the policy for your installation.
